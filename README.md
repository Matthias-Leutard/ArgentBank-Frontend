# Argent Bank – Application bancaire

Application web bancaire développée avec React dans le cadre du projet 10 de la formation Développeur Web OpenClassrooms.

## Technologies utilisées

- React 18
- Vite
- React Router
- Redux Toolkit
- React Redux
- CSS

## Installation

Cloner le dépôt :

```bash
git clone https://github.com/Matthias-Leutard/ArgentBank-Frontend.git
```

Installer les dépendances :

```bash
npm install
```

## Lancement du projet

Démarrer le serveur de développement :

```bash
npm run dev
```

L'application est accessible à l'adresse indiquée dans le terminal, généralement `http://localhost:5173`.

**Important :** le serveur backend Argent Bank doit également être lancé pour utiliser les fonctionnalités nécessitant l'API.

## Autres commandes

Compiler l'application pour la production :

```bash
npm run build
```

Vérifier le code avec ESLint :

```bash
npm run lint
```

## API

L'application communique avec le backend Argent Bank via l'API REST locale :

`http://localhost:3001/api/v1`
